# AKKI MEISTER — final identity + launch kit

**Logo** (`logo/`): cobalt-fade ///AM · Clash Grotesk wordmark · hairline rule ending in an inverted chequered flag leaning 12° with the mark. Dark and light, SVG + 3000 px PNG.

**Pattern system** (`patterns/pattern-system.png`): ten patterns, all derived from the mark:
1. Bar Field: the 13:8:5 bars as a rhythm
2. Pinstripe: the crossbar slit as hairlines with 13:8:5 cobalt runs
3. Grid Slots: the inverted chequer in perspective
4. Smear: the mark as a long exposure
5. Construction: 12° rails, φ guides, ratios
6. Flares: four-point apex flares on a 12° grid
7. Rails: outlined bars, one lit
8. Signal Dots: dot matrix along the 12° diagonal
9. Monogram Tile: the mark on an offset grid
10. Roundel icons (`patterns/highlight-roundels.png`): Instagram highlight covers

**Launch posts** (`posts/`, 1080×1350): Introducing · The Mark · /// Means · Lights Out Soon · Pattern / Out Now.
**Launch story** (`story/`, 1080×1920, post in order 01→06): Something is coming → Three bars → One line → Built to move → Reveal → Follow the line.
